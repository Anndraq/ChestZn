# ChestZn · Маркировка — desktop (PySide6)

Нативное Windows-приложение на Python + PySide6.
Собирается в один `ChestZn.exe` через PyInstaller.

## Требования

- Python 3.10+
- Windows 10/11
- **Ghostscript** (для рендера DataMatrix через treepoem)

### Установка Ghostscript

Windows:
    choco install ghostscript
или скачать с https://www.ghostscript.com/releases/gsdnld.html

Проверка:
    gswin64c --version

## Установка зависимостей

    pip install -r requirements.txt

## Запуск в dev-режиме

    python main.py

Откроется нативное окно с двумя вкладками: **Оператор** и **Админ**.

## Сборка .exe

    build.bat

Готовый файл: `dist\ChestZnr.exe`.

## Что работает

- Сканирование иностранного ШК (Enter в поле) → получение кода ЧЗ из мок-пула
- Рендер настоящего GS1 DataMatrix (treepoem)
- Предпросмотр русификатора
- Печать — помечает код использованным
- Админ: дашборд, очередь, точки, пользователи, интеграции,
  шаблоны, пул кодов, журнал
- Горячие клавиши: F2 (печать), F5 (повтор), F8 (пропустить), Esc (сброс)

## Что заглушки

- ГИС МТ — мок-пул кодов в памяти
- 1С — всегда timeout
- Парсер иностранного ШК — простой
- Авторизация не реализована
- Данные в памяти (при закрытии теряются)
