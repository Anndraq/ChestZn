\# Установка Ghostscript



\## Что это и зачем



Ghostscript — это интерпретатор PostScript.

Он нужен для рендера GS1 DataMatrix через `treepoem`.



\*\*Без Ghostscript коды DataMatrix не будут отображаться и печататься.\*\*



\## Установка



\### Вариант 1. Вручную (рекомендуется)



1\. Откройте https://www.ghostscript.com/releases/gsdnld.html

2\. Найдите раздел \*\*Ghostscript AGPL Release\*\*.

3\. Скачайте \*\*Windows (64 bit)\*\* — файл вида `gs10080w64.exe`.

4\. Запустите установщик.

5\. \*\*Важно:\*\* при установке поставьте галочку \*\*Add Ghostscript to PATH\*\*.

6\. Завершите установку.

7\. \*\*Перезапустите Visual Studio\*\* (или компьютер).



Проверка:



&#x20;   gswin64c --version



Должно вывести номер версии, например `10.08.0`.



\### Вариант 2. Через Chocolatey



Если у вас установлен Chocolatey:



&#x20;   choco install ghostscript -y



После установки \*\*перезапустите терминал\*\*.



\### Вариант 3. Через winget



&#x20;   winget install --id ArtifexSoftware.GhostScript



\## Если после установки команда `gswin64c` не находится



Скорее всего, Ghostscript не добавился в PATH.

Решение:



1\. Откройте \*\*Параметры → Система → О системе → Дополнительные параметры системы\*\*.

2\. \*\*Переменные среды\*\*.

3\. В разделе \*\*System variables\*\* найдите \*\*Path\*\* → \*\*Изменить\*\*.

4\. \*\*Создать\*\* → вставьте путь до папки `bin` Ghostscript:

&#x20;  `C:\\Program Files\\gs\\gs10.08.0\\bin`

5\. Сохраните.

6\. \*\*Перезапустите VS\*\* или компьютер.



\## Проверка в приложении



Запустите ChestZn. При старте приложение проверяет наличие Ghostscript.



Если Ghostscript \*\*не найден\*\* — увидите предупреждение:



\- DataMatrix не будет рендериться;

\- но остальная работа будет доступна.



\## Обновление Ghostscript



Обновлять нужно редко — раз в год или при критических уязвимостях.

Для рендера DataMatrix достаточно любой версии 10.x.
