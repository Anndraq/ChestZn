\## Быстрый старт



1\. Установите Python 3.9+ и Ghostscript 10.x.

2\. Запустите `ChestZn.exe` (или `python main.py` из исходников).

3\. Зайдите в \*\*Админ\*\* (пароль по умолчанию `admin` / `123`).

4\. Настройте принтер: \*\*Админ → Принтер → Обновить список → Выбрать → Сохранить\*\*.

5\. Вернитесь на \*\*Оператор\*\* и сканируйте штрихкоды.



\## Что делает приложение



\- Оператор сканирует иностранный штрихкод.

\- Приложение получает код «Честного знака» из базы.

\- Рендерит GS1 DataMatrix.

\- Автоматически печатает этикетку на принтере.



\## Кому адресовано это руководство



\- \*\*Администратору\*\* — тот, кто настраивает и обслуживает систему.

\- \*\*Оператору\*\* — тот, кто сканирует штрихкоды и печатает этикетки.
