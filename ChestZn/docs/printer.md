\# Настройка принтера



\## Какие принтеры поддерживаются



Приложение работает с любым принтером, который видит Windows:



| Тип принтера | Примеры | Как печатает |

|---|---|---|

| Zebra | ZD230, ZD421, GK420 | Напрямую по ZPL |

| TSC | TE200, TE300, TX200 | Напрямую по TSPL |

| Godex | G500, G530 | Напрямую по EZPL |

| Офисные | HP LaserJet, Canon | Через драйвер Windows |

| Виртуальный | Microsoft Print to PDF | Сохраняет в PDF |



Приложение \*\*определяет язык автоматически\*\* по имени принтера.



\## Шаг 1. Установите драйвер



1\. Скачайте драйвер с сайта производителя.

2\. Установите его.

3\. Убедитесь, что принтер появился в \*\*Параметры → Принтеры и сканеры\*\*.



\## Шаг 2. Подключите принтер



\- \*\*USB\*\* — подключите кабель, Windows поставит устройство.

\- \*\*Ethernet\*\* — узнайте IP принтера (обычно печатает тест-страницу).

\- \*\*Wi-Fi\*\* — подключите через настройки принтера.



\## Шаг 3. Настройте в ChestZn



1\. Зайдите в \*\*Админ → Принтер\*\*.

2\. Нажмите \*\*🔄 Обновить список\*\*.

3\. Найдите свой принтер в таблице.

4\. \*\*Кликните по строке\*\* — поля заполнятся автоматически.

5\. Проверьте параметры:

&#x20;  - \*\*Язык команд\*\* — определится сам (zpl / tspl / ezpl / windows);

&#x20;  - \*\*Ширина этикетки\*\* — 58 мм (по умолчанию);

&#x20;  - \*\*Высота этикетки\*\* — 40 мм;

&#x20;  - \*\*DPI\*\* — 203 или 300;

&#x20;  - \*\*Копий\*\* — 1.

6\. Нажмите \*\*💾 Сохранить\*\*.

7\. Проверьте через \*\*🧪 Тест печати\*\*.



\## Сетевой принтер (Ethernet)



1\. Узнайте IP принтера — обычно печатается на тестовой странице.

2\. В разделе \*\*Принтер\*\* введите IP в поле \*\*IP-адрес\*\*.

3\. Порт оставьте `9100`.

4\. Сохраните.



\## Типичные проблемы



\- \*\*Принтер не появляется в списке\*\* — установите драйвер, перезапустите VS.

\- \*\*Печатает пустые этикетки\*\* — проверьте, что ширина/высота совпадают с реальной этикеткой.

\- \*\*DataMatrix не сканируется\*\* — увеличьте DPI или размер.
